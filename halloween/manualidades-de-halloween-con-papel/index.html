Manualidades halloween fáciles de papel

Una de las manualidades más rápidas y sencillas que podemos hacer con papel para la época de Halloween, son sin duda las siluetas terroríficas. Podemos recopilar algunos papeles y cartulinas negras y recortar siluetas con motivos para Halloween cómo ratas, arañas, calaveras o murciélagos y colocarlos en algunos lugares de nuestra vivienda como si fueran sombras espeluznantes. Este tipo de proyecto es muy simple y podemos hacerlo muy fácilmente descargando algunas imágenes de Internet para poder reseguir su silueta sobre un papel oscuro y simular así estás sombras que nos servirán para ambientar nuestra fiesta de Halloween de una forma increíble.

Con la técnica del Kirigami también podemos hacer telarañas de papel que son súper fáciles y a los niños les encantará. Podemos usarlas después para decorar y ambientar algún espacio de una forma divertida y original.

Otro tipo de manualidad fácil con papel para Halloween, es sin duda las figuritas de origami que serán una forma excelente de realizar una actividad divertida e ideal para estas fechas. Podemos hacer fantasmas, gatos negros o murciélagos y luego utilizarlos para decorar y ambientar los espacios en nuestro evento de Halloween.

Manualidades Halloween papel de seda

El papel de seda nos puede venir muy bien para hacer algunas manualidades como por ejemplo divertidas piñatas para amenizar nuestra fiesta de Halloween. También podemos utilizar el papel de seda para hacer pompones y para otro tipo de decoraciones en las que busquemos esa estética delicada y ligera que nos ofrece este tipo de papel. Podemos entonces utilizar unos globos y un poco de papel de seda para hacer el faldón de unos divertidos fantasmas que nos ayuden a decorar nuestro espacio.

Otra de las propiedades que nos puede ofrecer el papel de seda, es sin duda su transparencia y podemos jugar con esta particularidad para crear sombras y colores utilizando velas y pequeñas luces que nos ayudarán ambientar los espacios ya crear misteriosas sombras. Podemos reutilizar algunos botes de cristal y cubrirlos con distintos trozos de papel de seda, también podemos hacer pequeños cuentitos utilizando cola blanca y simulando ser calabazas pero otra posibilidad también estupenda será decorar con este tipo de papel las ventanas de nuestra vivienda utilizando motivos frankenstein u otros personajes típicos de Halloween.

Manualidades de halloween con papel mache

El papel maché es otra de las técnicas interesantes para hacer manualidades de Halloween con papel. Lo bueno de esta técnica es que reutilizando papeles usados cómo es el papel de periódico, bien triturado y mezclado con cola obtenemos una pasta que podemos moldear y crear así figuras y piezas bastante resistentes y duraderas.

Podemos utilizar esta técnica entonces para decorar un siniestro árbol a partir de una rama seca que podemos pintar de negro y colgar ahí nuestras decoraciones de papel maché. Es una idea muy sencilla pero que nos ayudará adornar nuestro espacio de una forma muy original y que además quedará muy bien.También podemos utilizar esta técnica para crear figuras de un tamaño mayor que nos ayuden a decorar nuestra casa. Por ejemplo un gato negro o unas calabazas de papel maché pueden ser excelentes ideas para Halloween.

Decoraciones para halloween manualidades de papel

Las guirnaldas son una de las manualidades más típicas que podemos hacer con papel para decorar y que además no nos requerirá un gran esfuerzo. También podemos hacer rosetones y personalizarlos simpáticas telarañas o incluso personajes para colgar.
