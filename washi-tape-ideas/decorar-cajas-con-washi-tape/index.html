14 ideas para decorar cajas con washi tape

Las cajas son una de los elementos básicos de ordenación en una casa podemos utilizarlas en el estudio para ordenar papeles para el vestidor o en el armario y guardar todo tipo de objetos que no queremos que estén a la vista pero reconozcámoslo reciclar cajas no siempre es fácil porque muchas de ellas tienen logotipos de empresas y colores feos utilizar washi tape para decorar cajas es una de las mejores técnicas de manualidades que podemos hacer sencillas y baratas para igualar distintas cajas recicladas y conseguir un estilo uniforme y una estética mucho más armonioso con nuestra decoración y bonita.

Vamos a ver algunas ideas para decorar cajas con washi tape muy fáciles de realizar que nos van a permitir tener todo tipo de cajas recicladas super bonitas en nuestra casa para decorar.

Contenido

decorar cajas con washi tape

Podemos reciclar las típicas cajas de guardar folios y darles un toque especial utilizando cintas washi para decorarlas y conseguir resultados tan bonitos como estos o incluso podemos utilizar este tipo de cintas para decorar tubos de cartón de papel de váter y utilizar estos para hacer bonitos regalos y originales como veis se pueden reciclar todos estos desechos que habitualmente tiramos y convertirlos en bonitos regalos o en bonitas cajas decoradas siempre con cinta de washi tape.

envolver regalos con washi tape de cajas de tubos de cartón

Caja organizadora de washis

Otra opción que podemos hacer si queremos tener ordenados nuestras masking tape es utilizar las propias cintas para decorar divertidas cajas que no servían después para hacer un organizador de cintas artesanal para ellos solo necesitamos un tubo en el centro y una caja decorada con los distintos colores para que no sea muy fácil identificar las distintas tiendas washi que hay dentro del envase y colocarlo para tener todos los celos ordenados.

Revistero reciclado con cintas masking tape

Otra opción para decorar cajas utilizando masking tape y reciclar los típicos revisteros o archivadores de oficina que suelen ser muy feos y darle un toque colorido utilizando una amplia variedad de distintos colores de cintas washi que conviene euro se entrelazan dos uno encima de otro para hacer un arcoiris súper chulo que quedara genial decorando un salón.

Puntos de libro de cartón decorados con washitape

No solo podemos decorar cajas con cientos de washi tape también podemos aprovechar por ejemplo las tapas de estas para decorarlas con nuestras cintas favoritas y hacer bonitos cuadros que podemos colgar o incluso utilizar cartón de la propia caja recortado para hacer unos.s de es que podemos regalar a alguien en el día del libro.

Cajas decoradas con washi-tape y papel Kraft

Podemos envolver todo tipo de regalos utilizando cintas washi decorando estas cajas que habitualmente tiraría Moss y podremos conseguir resultados tan chulos como los que veis aquí no sólo se pueden cubrir las cajas con cinta Washi también podemos utilizar un cordón al que le pegamos distintas cintas de colores bonitos a modo de banderolas que pueden quedar genial.  Estaremos reutilizando un objeto que íbamos a desechar y encima estaremos ahorrando en papeles para envolver regalos de una forma mucho más creativa y original.

Decorando bolsas de regalo con cintas

También se pueden decorar bolsas de regalos o incluso todo tipo de tarjetas de felicitación hechas con la de cartón de una caja podemos reciclarlo y decorarlo con cintas washi conseguiremos resultados fantásticos.

Cajas metalicas decoradas con washi-tape

Otro tipo de cajas para decorar con cintas washi son las cajas metálicas que pueden conseguirse reciclando de otros usos por ejemplo podemos decorar estás utilizando cintas washi tape de una forma muy original y conseguiremos un resultado tan fantástico como el que veis aquí.

Incluso podemos convertir sobres de cartas en divertidos regalos y cajas decoradas con washi tape tan solo doblando de nuevo el papel para lograr un poco más de volumen y decorando las de una forma original con cintas que peguen con la época navideña o con el tipo de regalo que se quiere realizar.

Decora con washi tape cajas metálicas

Otro tipo de cajas que quedan fantásticas decoradas con cintas washi son las cajas metálicas podemos darle un toque nuevo muy distinto al original sin necesidad de pintarlas tan solo decorando las con unos pocos washis de colores que combinen entre sí.

Decora cajas de huevos con washitape

Podemos utilizar también las cintas washi para decorar cualquier tipo de caja no solo las típicas cajas de zapatos sino que podemos hacer divertidas creaciones utilizando las cajas de hueveras decoradas con washi tape y crear divertidos envoltorios de regalos muy originales tan solo necesitamos o bien pintarlas de un color bonito y combinarlo con unas pocas cintas o bien incluso el propio color neutro que ya llevan ellas y hacer con un poco de cordón y con unas pocas cintas washi un divertido y original envoltorio de regalo.

Como podéis ver los colores vivos sientan genial si luego los combinamos con cintas Washi de colores puedes hacer una manualidad infantil fantástica para regalar a alguien reciclando unas hueveras y decorando las con unas cintas muy originales.

Por último me gustaría enseñaros este ejemplo de caja decorada con cintas washi como veis tan solo leyendo un papel bonito y luego después dándole un toque de color con estas cintas podemos conseguir un resultado muy vistoso que puede encantar a cualquier persona que reciba el regalo se puede combinar esto con Becker Twain de un color que combine o también con cordeles naturales el papel kraft también es otro ejemplo de papel que puede funcionar muy bien combinado con las cintas washi porque es de un color muy neutro al que le podemos aplicar un toque de color utilizando este tipo de cintas, el contraste de la sencilla del papel kraft con los llamativos estampados de las cintas Washi de colorines puede hacer un efecto muy interesante y chulo que puede quedar genial decorando vuestros proyectos de manualidades.
