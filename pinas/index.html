Manualidades con piñas

  • Català
  • Español

Las piñas es uno de los materiales naturales que podemos encontrar en el bosque y que más se utilizan para hacer manualidades en las épocas de otoño y navidad. Su estética tan natural es perfecta para realizar proyectos sencillos ya se han decorativos o infantiles.

Las piñas, además de ser un material fácil de conseguir, permite muchas posibilidades a la hora de trabajarlo ya que lo podemos pintar, cubrir con purpurina, colgar junto a otros elementos incluso pegar para decorar.

Vamos a ver algunas ideas de proyectos diferentes qué podemos hacer utilizando piñas:

Manualidades con piñas de árbol para decorar

Las piñas, así como otros materiales naturales son perfectos para realizar decoraciones. Nosotros dan un aire muy natural a los espacios y además se trata de elementos muy sencillos de conseguir y muy agradecidos a la hora de trabajarlos.

Utilizando algunos de estos elementos, y por supuesto las protagonistas del artículo de hoy, qué son las piñas, podemos hacer adornos decorativos de pared tan bonitos como estos:

 

Se trata de una manualidad muy simple que podemos hacer tanto pequeños como mayores, pero que sin duda es perfecta para dar un toque diferente a algún rincón de nuestra vivienda.

En este caso y para conseguir una estética muy natural, se ha optado por cordones de algodón, una rama sin tratar y algunas piezas de madera en forma de corazón además de las piñas que se han cubierto con una fina capa de purpurina dorada para obtener una estética algo más elegante y glamurosa.

 

Otra de las ideas decorativas que podemos hacer también utilizando piñas y otros elementos naturales son este tipo de móviles, que además de ser muy visuales, pueden ser una excelente forma de aromatizar y ambientar nuestra vivienda con la llegada del otoño.

Para hacer este tipo de móviles podemos utilizar algunas especies y elementos aromáticos como la naranja, el clavo y la canela jugando así con un elemento decorativo ideal para todos los sentidos.

 

Manualidades con piñas para niños

También para hacer algunas manualidades infantiles, las piñas son grandes aliadas. Podemos hacer un montón de manualidades con ellas, incluso utilizarlas para complementar algunas otras, cómo es el ejemplo de la casita de árbol qué vais a continuación elaborada a partir de palitos, troncos, piedras y todo tipo de elementos procedentes del bosque.

Manualidades con piñas para Navidad

En Navidad, las piñas también son muy habituales y pueden sernos de gran utilidad para realizar un montón de manualidades. En la guía para decorar mesas navideñas, veréis la aplicación de este elemento natural en distintos proyectos navideños.

Podemos utilizar las piñas para hacer centros de mesa, incluso para adornarla colocando algunas de forma alternada por toda la mesa, podemos también utilizar las para poner el nombre de nuestros invitados o incluso para hacer divertidos servilleteros.

Combinando las piñas con otros elementos que desprendan olores que representen para nosotros el otoño, podemos hacer ambientadores super naturales y que además quedan preciosos para decorar cualquier rincón.
