Hola a todos y bienvenidos a uma Manualidades, hoy vamos a hacer unas botellas sensoriales montessori para bebés. Este tipo de manualidades para bebés son muy sencillas y permite a los bebés experimentar con los colores y las luces así como las formas y podemos hacerlas inspiradas en muchas temáticas diferentes.

Materiales para hacer botellas sensoriales para bebés

botellas de plástico que sean pequeñas
elementos para decorar como abalorios y figuritas de plástico
washi tape
pegamento
colorantes alimenticios

Cómo hacer botellas sensoriales montessori para bebés

1 Primero escogeremos los elementos que queremos para decorar nuestras botellas sensoriales para niños en este caso vamos a hacer una botella sensorial montessori inspirada en el mar y por eso utilizaremos diferentes piezas de plástico que no recuerden al mar.
2 Teñiremos el agua con colorante azul y lo introduciremos todo dentro de nuestra botella para asegurarnos de que no se abra y sea peligroso para los más pequeños
3 Taparemos bien la manualidad para bebés pero antes le colocaremos un poco de pegamento para que no se pueda abrir
4 Lo acabaremos de decorar con un poco de washi tape y ya tenemos nuestra botella sensorial para bebés inspirada en el mar.
